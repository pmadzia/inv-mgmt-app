# Inventory Management App
A web application for managing inventory, built with Ruby on Rails.
Link to app: [Inventories](https://inv-mgmt-app.onrender.com)

## Features
- Create account and sign-in
- Sign-in with Google and GitHub accounts (OmniAuth)
- Admin panel (manage users)
- Language selection
- Light/Dark theme

## Tech Stack
- *Framework*:	Ruby on Rails 8.1
- *Database*: PostgreSQL
- *Web server*:	Puma (with Thruster)
- *Frontend*:	Hotwire (Turbo + Stimulus)
- *Authentication*:	OmniAuth (omniauth-google-oauth2, omniauth-github)
